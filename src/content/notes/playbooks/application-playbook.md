## The daily 10

- **5 from the scheduled shortlist** (lands ~9:04 IST in Claude as a message + a dated file). The run has already bucketed them P1/P2/P3 and drafted an application note each.
- **5 sourced live** — the [[playbooks/linkedin-sourcing|saved searches]], newest first, posted ≤14 days.
- **P3 long shots: 2 max** count toward the 10. They feel productive and convert worst.

## Per application (10 minutes, hard cap)

1. **Dedupe first.** Search Applications by company. Already there? Skip — the duplicate warning exists for a reason.
2. **Apply** with `GirijaShankar_Vajrapu_CV.pdf` — the one standard file, unchanged.
3. **The "why me" box** gets the 4-sentence note: open the record → Send tab → Application note → Copy. Swap at most ONE clause for something from the JD. More editing than that is the tailoring spiral in disguise.
4. **One connect note** to the recruiter or hiring manager (the Opener, same tab).
5. **Log it:** status Applied (stamps today + the Day-3 follow-up), Segment = bucket, posting URL, source.

## The note formula (why 4 sentences beat a cover letter)

Sentence 1: the role, named. Sentence 2: the intersection (12y SAP finance + 3y production GenAI). Sentence 3: one concrete proof (14-market SAC rollout, or the live collections agent). Sentence 4: logistics — remote from India, UK/US overlap, start in two weeks. Recruiters skim; four load-bearing sentences survive skimming.

## Follow-up cadence

- **Day 3** — fu1: short nudge + the 3-minute-demo offer.
- **Day 7** — fu2: the last one, graceful. Then the record rests; no third nudge, ever.
- **Reply received** → answer the same day; offer **two concrete slots** (19:30–21:30 IST tonight / same window tomorrow — that's 2–4pm UK, 9–11am ET), never "sometime this week".

## What never happens

- No per-role CV. No cover letters unless the form physically requires one (then: the application note, expanded by one sentence).
- No applications outside the 09:00–12:00 block. Evening energy goes to booked calls, not more forms.
- No ghosting shame-spirals: Rejected / closed is a status, not a verdict. Log it, next.

## The four numbers (Block E, out loud)

**Applied / Replies / Interviews booked / Offers.** The KPI strip computes them from this tracker; saying them out loud is what makes the day feel finished — the RAMS trick, kept.
